# ESSENZA — Perfumería original (Sprint 2)

Sitio de ejemplo (marca ficticia) con Node.js + Express y estructura MVC. En este sprint solo se trabaja la estructura y estética (maqueta).

## Tablero de trabajo
Enlace: **PEGAR_AQUÍ_EL_LINK_DE_TRELLO_O_GITHUB_PROJECTS**

## Ejecutar
```
npm install
npm start   # http://localhost:3000
```

## Estructura
```
app.js                      servidor Express
routes/index.js             rutas
controllers/pageController.js
views/                      index, productDetail, productCart, register, login (.html)
public/css/styles.css       estilos compartidos
```

## Rutas
`/` · `/producto/:id` · `/carrito` · `/registro` · `/login`
