# Retrospectiva – Sprint 4



## 1. Comenzar a hacer 

- Guardar productos y usuarios en archivos JSON en lugar de dejarlos escritos en el código.
- Conectar los formularios al servidor desde el principio (`method`, `action` y `name` en cada campo), en lugar de dejarlos como maqueta.
- Pedir a cada compañero que instale y ejecute el proyecto en su computador (`npm install` y `npm start`) antes de cerrar el sprint.


## 2. Hacer más 

- Commits pequeños y frecuentes, con mensajes claros.
- Hacer `git pull` antes de empezar a trabajar y antes de cada `push`, para evitar conflictos.
- Probar cada función apenas se termina (crear, editar, eliminar, registro, login y carrito).
- Reutilizar los archivos parciales de EJS (head, header, footer, tarjeta de producto).

## 3. Continuar haciendo 

- Separar el proyecto en rutas, controladores, modelos y vistas.
- Mantener el diseño consistente en todo el sitio (tema oscuro y dorado).
- Usar el tablero de trabajo para repartir y seguir las tareas.
- Documentar con README a medida que se avanza.

## 4. Hacer menos 

- Dejar la documentación y las pruebas para el último día.
- Editar los mismos archivos entre varias personas sin avisar, porque genera conflictos de Git.
- Dejar datos de ejemplo escritos a mano dentro de las vistas.

## 5. Dejar de hacer 

- Subir cambios sin comprobar en qué rama se está trabajando.
- Dar una tarea por terminada solo porque "se ve bien", sin comprobar que funciona (botones sin conectar, formularios que no envían).
- Subir `node_modules` a GitHub (se ignora con `.gitignore`).

## Conclusiones principales

1. En el Sprint 3 la parte visual quedó resuelta, pero varias pantallas (formularios, carrito) eran maqueta y no funcionaban. Para el Sprint 4 priorizamos que todo trabaje con datos reales.
2. Los conflictos de Git y las dependencias sin instalar nos hicieron perder tiempo. Vamos a usar `git pull` antes de trabajar y a documentar la instalación en el README.
3. Dividir el trabajo en tareas pequeñas en el tablero ayuda a ver el avance de cada integrante.
