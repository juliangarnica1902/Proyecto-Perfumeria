# ESSENZA – Perfumería en línea (Sprint 2)

Maqueta web de una perfumería de autor desarrollada con **Node.js + Express**, HTML y CSS. En este sprint se construyen las páginas principales del sitio y la navegación entre ellas.

## Tablero de trabajo

🔗 **Tablero:** <PEGA_AQUÍ_EL_ENLACE_A_TU_TABLERO> (Trello / GitHub Projects / Jira)

## Temática del sitio

ESSENZA es una perfumería en línea de fragancias de autor. El sitio transmite elegancia y exclusividad con una estética oscura y dorada, y presenta cada perfume con sus notas olfativas para que el cliente elija con información clara.

## Público objetivo

- Adultos de 18 a 45 años que compran perfumes para uso personal o como regalo.
- Personas que prefieren comprar desde el celular.
- Clientes que buscan fragancias cuidadas y diferentes a las de las grandes marcas comerciales.
- Compradores de fechas especiales (cumpleaños, aniversarios, Día de la Madre, Navidad).
